ระบบแนะนำหลักสูตรจาก 39 มหาวิทยาลัยหลัก (74 วิทยาเขต) 2,233 หลักสูตร 20 กลุ่มสาขา โดยให้ผู้ใช้บอกข้อมูลของตัวเอง (คะแนน งบ ที่อยู่ สาขาที่สนใจ) และบอกว่าให้ความสำคัญกับอะไร แล้วจัดอันดับด้วยวิธี Simple Additive Weighting (SAW)

## วิธีรัน

### แบบที่ 1: Docker (ง่ายที่สุด ต้องติดตั้ง Docker Desktop)

```bash
docker compose up --build
```

เปิด http://localhost:4000 ระบบจะสร้างตารางและใส่ข้อมูลตั้งต้นให้เองตอนเปิดครั้งแรก

### แบบที่ 2: รันเอง (Node.js 22 ขึ้นไป + PostgreSQL)

```bash
# 1) สร้างฐานข้อมูล (ใน psql หรือ pgAdmin)
CREATE USER dss WITH PASSWORD 'dss';
CREATE DATABASE dss OWNER dss;

# 2) ติดตั้งแพ็กเกจ (ทำครั้งเดียว)
npm run setup
cp server/.env.example server/.env        # แก้ DATABASE_URL ถ้าใช้ user/รหัสอื่น

# 3) เปิด 2 terminal
npm run dev:server      # API ที่ http://localhost:4000 (สร้างตาราง + ข้อมูลตั้งต้นอัตโนมัติ)
npm run dev:client      # หน้าเว็บที่ http://localhost:5173
```

คำสั่งอื่นที่ใช้บ่อย
- `npm run db:reset` (หรือ `docker compose exec app npm run db:reset`): ล้างฐานข้อมูลแล้วใส่ข้อมูลตั้งต้นใหม่ **ควรรันก่อนนำเสนอ และต้องรันทุกครั้งที่โครงสร้างตารางเปลี่ยน**
- `npm test`: ทดสอบ SAW Engine (มีเคสตรวจตัวเลขให้ตรงกับตัวอย่างในสไลด์ Project-1 หน้า 9)
- `npm --prefix server run check:data`: ตรวจความสมเหตุสมผลของข้อมูลตั้งต้น (หลักสูตรซ้ำ ช่วงค่าเทอม พิกัด ระยะทาง สถิติคะแนน)
- `npm --prefix server run check:personas`: ดูคำแนะนำที่ระบบให้กับผู้ใช้จำลองหลายแบบ
- `npm --prefix server run check:api`: ทดสอบ API กับระบบที่รันอยู่ (สิทธิ์เข้าถึง กรณีขอบ ตรรกะการจัดอันดับ งาน Admin) **ใช้กับฐานข้อมูลทดสอบเท่านั้น** เพราะสร้างผู้ใช้ทดสอบและแก้/คืนค่าข้อมูลระหว่างรัน

## วิธีใช้งาน (นักเรียน)

คู่มือฉบับเต็มพร้อมภาพหน้าจอ (รวมการปักหมุดบ้านบนแผนที่ การใช้งานบนโทรศัพท์ และหน้าผู้ดูแลระบบ): [docs/USER_GUIDE.md](docs/USER_GUIDE.md)

1. **กรอกข้อมูลของคุณ** ในหน้า "วิเคราะห์และจัดอันดับ": GPA, คะแนนสอบ (%), งบค่าเล่าเรียนต่อปี, ที่อยู่ (กด "ใช้ตำแหน่งปัจจุบัน" หรือเลือกจังหวัด) และสาขาที่สนใจ
2. **บอกว่าอะไรสำคัญ**: กดปุ่มสำเร็จรูป (เน้นประหยัด / เน้นชื่อเสียง / เน้นโอกาสสอบติด / เน้นใกล้บ้าน) หรือเลื่อนแถบน้ำหนักเองให้รวม 100%
3. **คัดกรอง**: ระบบเปิด "เฉพาะสาขาที่สนใจ" และ "ไม่เกินงบ" ให้อยู่แล้ว เปิด "เฉพาะที่คะแนนถึงเกณฑ์" เพิ่มได้
4. **ดูผล**: อันดับ 1 คือหลักสูตรที่เหมาะกับคุณที่สุด กดระยะทางเพื่อเปิดเส้นทางใน Google Maps กด "+ เทียบ" เพื่อเปรียบเทียบสูงสุด 4 หลักสูตร แล้วกด "บันทึกผลการประเมิน" เพื่อเก็บไว้และเปิดรายงาน PDF

## เกณฑ์ที่ใช้ตัดสินใจ

| เกณฑ์ | ค่าดิบ | ปรับสเกลเป็น 0–1 | น้ำหนักเริ่มต้น |
|---|---|---|---|
| ค่าเล่าเรียนต่อปี | ค่าเทอม × จำนวนเทอมต่อปี | ต่ำสุดในกลุ่ม ÷ x | 35% |
| โอกาสสอบติด | 0–100% (ดูแบบจำลองด้านล่าง) | x ÷ 100 | 30% |
| อันดับมหาวิทยาลัย | ลำดับในไทยตาม THE WUR 2026 | (แย่สุด − x) ÷ (แย่สุด − ดีสุด) | 20% |
| ความใกล้บ้าน | 100 ที่ 0 กม. ลดเป็น 0 ที่ 1,000 กม. | x ÷ 100 | 15% |

คะแนน SAW = Σ (ค่าที่ปรับสเกล × น้ำหนัก) × 100 คะแนนเท่ากันได้อันดับร่วม

**แบบจำลองโอกาสสอบติด**
- หลักสูตรที่มีสถิติจริง: ดูว่าคะแนนของผู้ใช้อยู่ตรงไหนระหว่างคะแนนต่ำสุดกับสูงสุดของผู้ที่สอบติดปีก่อน เท่าคะแนนต่ำสุด = 50%, ถึงคะแนนสูงสุด = 95%, ต่ำกว่าต่ำสุดเท่าช่วงนั้น = 5%
  - คะแนนของผู้ใช้ที่นำไปเทียบ = สัดส่วน GPAX ของหลักสูตร × (GPA ÷ 4 × 100) + ส่วนที่เหลือ × คะแนนสอบ (%) เพราะแต่ละหลักสูตรใช้ GPAX ในคะแนนคัดเลือกไม่เท่ากัน (เช่น ม.ศรีปทุมใช้ GPAX 100% ส่วนจุฬาฯ ส่วนใหญ่ใช้ 0%) สัดส่วนนี้มาจากประกาศเกณฑ์รอบ 3 ของแต่ละหลักสูตร
  - **ถ้าผู้ใช้กรอกคะแนนรายวิชา** (TGAT, TPAT1–5, A-Level 10 วิชา — ไม่บังคับ) และหลักสูตรนั้นมีสูตรคะแนนตามประกาศ ระบบคิดคะแนนรวมตามสูตรจริงของหลักสูตร เช่น TGAT 20% + คณิต 1 40% + อังกฤษ 40% วิชาในสูตรที่ไม่ได้กรอกใช้คะแนนสอบรวมแทน หลักสูตรที่ไม่มีสูตรใช้วิธีข้างต้น
  - ถ้าหลักสูตรประกาศ GPAX ขั้นต่ำ และ GPA ของผู้ใช้ไม่ถึง จะขึ้นป้าย "GPA ต่ำกว่าเกณฑ์"
- หลักสูตรที่ไม่มีสถิติ: ประมาณจากส่วนต่าง GPA (40%) และคะแนนสอบ (60%) กับเกณฑ์ขั้นต่ำโดยประมาณ
- ระดับความเสี่ยง: ต่ำ (70% ขึ้นไป) ปานกลาง (45–69%) สูง (ต่ำกว่า 45%)

**กฎคัดกรอง (Business Rules)**: เฉพาะสาขาที่สนใจ, ค่าเล่าเรียนต่อปีไม่เกินงบ, คะแนนถึงเกณฑ์, เฉพาะภูมิภาคที่สนใจ

**การวิเคราะห์ความไว (Sensitivity)**: ปรับน้ำหนักทีละเกณฑ์ ±10 และ ±20 จุด (เกณฑ์อื่นปรับตามสัดส่วน) แล้วดูว่าอันดับ 1 เปลี่ยนหรือไม่ ความเสถียร = สัดส่วนของสถานการณ์ที่อันดับ 1 คงเดิม

ข้อควรรู้เกี่ยวกับข้อมูล
- **คะแนนในสถิติ ทปอ. เป็นคะแนนรวมถ่วงน้ำหนักตามเกณฑ์ของแต่ละหลักสูตร** (สัดส่วน GPAX/TGAT/TPAT/A-Level ต่างกัน) ระบบแยกได้เฉพาะส่วนของ GPAX กับส่วนของคะแนนสอบ โดยรับ "คะแนนสอบ (%)" ของผู้ใช้เป็นตัวเลขเดียว การเทียบจึงยังเป็นการประมาณ
- **ราชภัฏชัยภูมิ** ใช้ประกาศปี 2561 (ฉบับล่าสุดที่เว็บงานทะเบียนเผยแพร่) **ม.ศรีปทุม** ไม่ได้แจ้งค่าใช้จ่ายกับ ทปอ. จึงใช้ยอดตลอดหลักสูตรปี 2568 ÷ 8 (คณะที่ประกาศเป็นช่วงใช้ค่ากลาง) **มทร.รัตนโกสินทร์** แจ้งเพียง "สายวิทย์ 15,000 สายสังคม 12,000" ระบบแยกสายจากชื่อปริญญา
- **ม.รามคำแหง** ค่าเทอมราว 1,400–4,000 บาท/ภาค (หน่วยกิตละ 25 บาท) เมื่ออยู่ในตัวเลือก คะแนนเกณฑ์ค่าเล่าเรียนของหลักสูตรอื่นจะต่ำลงมาก เพราะสูตร min ÷ x เทียบกับตัวที่ถูกที่สุด
- **ชื่อหลักสูตรตัดคำนำหน้าออกอัตโนมัติ** จากชื่อในไฟล์ ทปอ. (เช่น "หลักสูตรวิทยาศาสตรบัณฑิต สาขาวิชา…")
- **นำเข้าเฉพาะหลักสูตรภาคปกติ** หลักสูตรนานาชาติ ภาคพิเศษ สองปริญญา และต่อเนื่อง ไม่นำเข้าเพราะค่าเทอมคนละอัตรา (ยกเว้น มฟล. ที่สอนเป็นภาษาอังกฤษเป็นปกติ)
- **แยกวิทยาเขตเป็นคนละรายการเมื่ออยู่คนละจังหวัด** เช่น ศิลปากร (สนามจันทร์ / วังท่าพระ), มทร.อีสาน (นครราชสีมา / สุรินทร์ / ขอนแก่น / สกลนคร), สถาบันพระบรมราชชนก (วิทยาลัยพยาบาลและสาธารณสุข 39 แห่ง) วิทยาเขตรองของมหาวิทยาลัยชุดแรก (มก., ม.อ., มธ., ม.มหิดล, มศก., มจพ., สจล., ม.ทักษิณ) ใช้ค่าเทอมที่แจ้ง ทปอ. ไม่ใช้ตารางรายคณะของวิทยาเขตหลัก
- **ค่าเทอมที่มหาวิทยาลัยแจ้ง ทปอ. มีรูปแบบไม่เหมือนกัน**: บางแห่งแจ้งต่อภาค บางแห่งแจ้งยอดตลอดหลักสูตร (ระบบหารด้วยจำนวนภาค: 4 ปี = 8, สถาปัตย์ 5 ปี = 10, แพทย์/ทันตะ/เภสัช/สัตวแพทย์ = 12) ราชภัฏธนบุรีแจ้งเฉพาะยอดภาคแรกเข้าโดยประมาณ ตัวเลขเดี่ยวตั้งแต่ 60,000 บาทขึ้นไปถือเป็นยอดตลอดหลักสูตร
- **มน.** ใช้ตารางที่ใส่เอง (รวมค่าธรรมเนียมอื่น 1,100 บาท/ภาค) แทนค่าที่แจ้ง ทปอ. ซึ่งเป็นค่าเล่าเรียนอย่างเดียว
- **มจธ., มทส., ม.กรุงเทพ, ม.รังสิต** ไม่ได้เก็บค่าเทอมแบบเหมาจ่ายรายเทอม จึงคิดเป็นค่าเฉลี่ยจากยอดตลอดหลักสูตร
- **มวล. และ มทส.** ใช้ระบบไตรภาค ค่าเล่าเรียนต่อปีจึงคิดเป็นค่าเทอม × 3
- **ม.พะเยา** นำเข้าเฉพาะคณะที่แหล่งระบุค่าเทอมเป็นอัตราเดียว (คณะที่ระบุเป็นช่วงไม่นำเข้า) และ **ม.ทักษิณ** แหล่งข้อมูลค่าเทอมไม่ระบุปีการศึกษา
- **มก.** เป็นตัวเลขโดยประมาณรายคณะตามที่แหล่งระบุ
- ทุกค่าแก้ได้ในหน้า Admin หรือนำเข้าผ่าน CSV

วิธีอัปเดตสถิติ TCAS ปีใหม่: ดาวน์โหลดไฟล์ Excel จาก mytcas.com/stat แล้วรัน
```bash
cd server && npm i --no-save xlsx
node db/tools/build-cost.cjs <courses.json ปีเดียวกับสถิติ> [courses.json ปีอื่น]   # ค่าเทอมรายหลักสูตรที่มหาวิทยาลัยแจ้ง ทปอ.
node db/tools/fetch-criteria.cjs <ไฟล์.xlsx>            # ดึงเกณฑ์รอบ 3 (สัดส่วน GPAX, GPAX ขั้นต่ำ) จาก mytcas
npx tsx db/tools/build-tcas.ts <ไฟล์.xlsx> --report --write
```
ชื่อที่จับคู่ไม่ได้อัตโนมัติ เพิ่มได้ใน `server/db/tools/tcas-alias.json`

## ลำดับเดโมที่แนะนำ (ประมาณ 5 นาที)

1. เข้าสู่ระบบเป็น **นักเรียน** ไปหน้า "วิเคราะห์และจัดอันดับ" กด **"ใช้ตำแหน่งปัจจุบัน"** แล้วเลือกสาขา เช่น คอมพิวเตอร์และไอที ให้ดู KPI 4 ช่อง กราฟ Top 10 และระยะทางถึงแต่ละมหาวิทยาลัย
2. กดปุ่ม **"เน้นใกล้บ้าน"** แล้ว **"เน้นชื่อเสียง"** ให้เห็นว่ากราฟและอันดับ 1 เปลี่ยนทันที (Model + Visualization)
3. ลดงบค่าเล่าเรียนต่อปีลง ให้เห็นว่าตัวเลือกถูกคัดออกพร้อมเหตุผล (Business Rules)
4. แก้คะแนนสอบให้ต่ำลง ให้เห็นโอกาสสอบติดลดลงและกล่องเตือนสีแดงเมื่อเสี่ยงสูง (What-if + Risk Model)
5. กด **"ดูการวิเคราะห์เชิงลึก"** แล้วอธิบายตาราง Sensitivity ว่าคำแนะนำเสถียรแค่ไหน
6. กด "+ เทียบ" 2–3 หลักสูตร ไปหน้า **เปรียบเทียบ** (ตาราง + เรดาร์ + ที่มาเกณฑ์รับ) จากนั้นกด **บันทึกผลการประเมิน** แล้วเปิด **รายงาน PDF**
7. ออกจากระบบ แล้วเข้าใหม่เป็น **Admin** เพื่อโชว์ Dashboard, การแก้หลักสูตร, การนำเข้า CSV และการแก้เกณฑ์ จากนั้นกลับไปหน้านักเรียนให้เห็นว่าผลลัพธ์เปลี่ยนตาม

## สิ่งที่ต่างจากเอกสาร Project-1 (ควรเล่าตอนนำเสนอ)

**โครงสร้างข้อมูล**
- **เพิ่มตาราง `evaluation_run`** เพื่อรวมผลที่คำนวณในรอบเดียวกัน เพราะในแบบเดิม `EVALUATION` ผูกกับหลักสูตรทีละแถว จึงดูประวัติย้อนหลังเป็นรอบไม่ได้ ทำให้ระบบมี 10 ตาราง
- **ใช้ชื่อตาราง `users`** แทน `USER` เพราะ USER เป็นคำสงวนของ PostgreSQL
- **เปลี่ยนคะแนนสอบเป็นระบบ TCAS ปัจจุบัน** (คะแนนรวมคิดเป็นร้อยละ) แทน O-NET/GAT-PAT ที่เลิกใช้แล้ว โดยใช้คอลัมน์ `exam_score`
- **คอลัมน์ที่เพิ่ม**: `program.yearly_cost`, `program.max_score`, `program.applicants`, `program.score_source`, `university.lat/lng`, `student_profile.home_province`, `student_profile.home_lat/home_lng`

**เกณฑ์**
- **ใช้ 4 เกณฑ์ที่มีข้อมูลรองรับ** ตัดอัตรามีงานทำและเงินเดือนเริ่มต้นออก เพราะไม่มีแหล่งข้อมูลรายหลักสูตรที่ตรวจสอบได้
- **อันดับเป็นอันดับมหาวิทยาลัย** เพราะในไทยไม่มีการจัดอันดับรายหลักสูตรอย่างเป็นทางการ
- **ค่าเล่าเรียนเทียบเป็นรายปี** เพราะบางมหาวิทยาลัยมี 3 เทอมต่อปี ถ้าเทียบต่อเทอมจะดูถูกกว่าความจริง หน้าเว็บยังแสดงค่าเทอมต่อเทอมคู่กัน
- **ความใกล้บ้านคิดจากระยะทางจริง** จากตำแหน่งของผู้ใช้ถึงพิกัดมหาวิทยาลัย แทนการเช็กแค่ภูมิภาค

**สูตรปรับสเกล** (รายงานเดิม: benefit = x ÷ max, cost = min ÷ x ทุกเกณฑ์)
- **อันดับใช้แบบเส้นตรง** เพราะเป็นข้อมูลเชิงลำดับ ถ้าใช้ min ÷ x อันดับ 2 จะได้คะแนนเพียงครึ่งเดียวของอันดับ 1
- **เกณฑ์ที่เป็นร้อยละ (โอกาสสอบติด, ความใกล้บ้าน) ใช้ x ÷ 100** เพราะถ้าทุกตัวเลือกมีโอกาสสอบติด 5% เท่ากัน สูตร x ÷ max จะให้ทุกตัวได้คะแนนเต็ม ทำให้ระบบแนะนำหลักสูตรที่แทบไม่มีโอกาสสอบติด
- **ค่าเล่าเรียนยังใช้ min ÷ x** ตามรายงานเดิม

**พฤติกรรมของระบบ**
- **ต้องเลือกสาขาที่สนใจก่อนจัดอันดับ** เพราะการเทียบข้ามสาขาให้ผลที่ไม่มีความหมาย (มีปุ่มให้ดูทุกสาขารวมกันได้)
- **เตือนเมื่อคำแนะนำไม่น่าเชื่อถือ**: อันดับ 1 เสี่ยงสูง, คะแนนเท่ากัน, ไม่เหลือตัวเลือกพร้อมบอกเหตุผล
- **รายงาน PDF** สร้างเป็นหน้า HTML แล้วให้เบราว์เซอร์สั่งพิมพ์หรือบันทึกเป็น PDF เพราะแสดงภาษาไทยได้สมบูรณ์กว่าการสร้าง PDF ฝั่งเซิร์ฟเวอร์

## ข้อจำกัดที่ทราบ

- **ระบบแสดงเฉพาะมหาวิทยาลัยหลัก 39 แห่ง** (รัฐชั้นนำ พระจอมเกล้า ราชมงคล เอกชนขนาดใหญ่ และวิทยาเขตรองของแห่งเหล่านี้) อีก 34 สถาบัน (ราชภัฏ 13 แห่ง, วิทยาลัยในสังกัดสถาบันพระบรมราชชนก, มหาวิทยาลัยสงฆ์, รัฐและเอกชนขนาดเล็ก) มีข้อมูลพร้อมแต่ปิดไว้ในรายการ `EXCLUDED` ของ `server/db/data.ts` ลบชื่อออกจากรายการแล้ว `npm run db:reset` เพื่อเปิดใช้
- ข้อมูลที่เตรียมไว้ครอบคลุม 73 สถาบันจากไฟล์ ทปอ. ที่ขาดคือ ม.วงษ์ชวลิตกุล และ ม.นานาชาติเอเชีย-แปซิฟิก (หาค่าเทอมไม่พบ) กับ ม.คริสเตียน และวิทยาลัยดุสิตธานี (ไม่มีหลักสูตรภาคปกติในสถิติรอบ 3) บางแห่งมีไม่ครบทุกหลักสูตร เช่น ม.มหานคร (เฉพาะสัตวแพทย์) วิทยาเขตรองที่มหาวิทยาลัยไม่ได้แจ้งค่าใช้จ่ายกับ ทปอ. ยังไม่ได้นำเข้า: มก. สกลนคร, มข. หนองคาย, ม.บูรพา จันทบุรี/สระแก้ว, ม.ศรีปทุม ชลบุรี/ขอนแก่น, มจธ. ราชบุรี
- เกณฑ์รับ 8 หลักสูตรยังเป็นค่าประมาณ และไม่มีข้อมูลรอบ Portfolio/Quota
- สูตรคะแนนรายวิชามีเพียง 485 จาก 2,225 หลักสูตร ที่เหลือยังเทียบด้วยคะแนนสอบรวมตัวเดียว แม้ผู้ใช้จะกรอกคะแนนรายวิชาแล้ว
- สัดส่วน GPAX ของหลักสูตรราวสองในสามเป็นค่ากลางของมหาวิทยาลัยเดียวกัน เพราะ ทปอ. ยังไม่ประกาศเกณฑ์รอบ 3 ของปีล่าสุด
- ระยะทางเป็นเส้นตรง ไม่ใช่ระยะหรือเวลาเดินทางจริง (กดลิงก์ไป Google Maps เพื่อดูเส้นทางจริงได้)
- อันดับเป็นระดับมหาวิทยาลัย และ THE จัดเป็นช่วง หลายแห่งจึงได้ลำดับเท่ากัน
- ระบบไม่รู้เนื้อหาหลักสูตรหรือความถนัดของผู้ใช้ แนะนำจาก 4 เกณฑ์ข้างต้นเท่านั้น
